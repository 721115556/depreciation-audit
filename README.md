# 固定资产折旧智能重算与差异测试

安永 AI 团队赛项目。我们计划制作固定资产折旧复核工具：读取台账，按直线法逐项重算当月折旧，与企业账面值比较，识别异常并生成审计工作底稿。

## 任务概览

输入为固定资产台账 Excel，包含资产编码、分类、原值、残值、计划使用年限、已使用月数、账面当月折旧、累计折旧和报废标识等。提供的测试台账约有 1.2 万条记录。

基本公式：`月折旧 = (原值 - 残值) / (计划使用年限 × 12)`。程序还需处理已提足、报废、最后一个月尾差、原值为零和残值不合理等情况，并计算差异和异常原因。

输出一个 Excel 工作簿，包含：

1. **折旧测算结果**：逐条列出测算值、账面值、差异、状态和原因，异常行标红。
2. **异常资产汇总**：列出异常资产及原因。
3. **分类汇总统计**：按资产分类汇总数量、原值、折旧、差异和异常数。
4. **统计总览**：展示资产数量、状态分布、测算及账面折旧总额。

评审重点为计算准确性（45 分）、输出规范（25 分）、大数据量稳定性（15 分）和功能与易用性（15 分）。最终要求以赛题说明为准。

## 团队协作

团队由两名 Trae 使用者和两名 GPT Plus 使用者组成，分别负责核心计算、Excel 输出、业务规则与测试、项目整合与展示。详细阶段安排、交付标准和提示词见 [团队分工与工作计划](docs/team-plan.md)。

建议每人使用独立分支，通过 Pull Request 交叉检查后合并到 `main`。赛题原始资料和测试数据暂不上传公开仓库，先确认赛事对材料公开的规定；测试可先使用自行构造的小样本。
